Added documented Tailwind v3/v4 syntax compatibility for important modifiers and parenthesized values, with a source-linked coverage matrix.

Implementation commit: cb20bdd74c69e168e399a28f90b37577c36ae4cb on local branch sdd/2e8-measure-production-tokenizer.

All six acceptance criteria are met. docs/tailwind-compatibility.md distinguishes v3, v4.0 and later v4 additions, grammar recognition, default theme coverage and deferred features. Both documented important placements work without version detection: !flex, hover:!flex, flex! and hover:flex!. The extension's !hover:flex form remains explicitly labeled compatibility behavior.

syntax.ts protects brackets, parentheses, quotes and escaped delimiters while locating variant boundaries and a single important marker. Theme lookup receives marker-free utility names, while emitted fragments retain exact UTF-16 source offsets. Important markers have independent ranges and are excluded from class decorations, including the final-prefix fallback for an unstyled base. Disabled important/prefix/base rules remain independent. Typed parenthesized values use the same theme lookup rules as bracketed equivalents. Lone/repeated markers yield no fragments; incomplete groups remain bounded without throwing.
