# Local 0.3.0 candidate

Prepared October 24, 2026, under plan `20261024-201053-d-ops-vgp`. This candidate
is unreleased. No push, merge, tag, GitHub release or publication was performed.

The root-level `tailwind-rainbow-0.3.0.vsix` contains the updated README,
Unreleased changelog and version/setting descriptions. The previously tested
`tailwind-rainbow.vsix` remains version 0.2.1 with its original archive hash.
[Verification data](0.3.0-verification.json) identifies both artifacts.

## Documentation and metadata

The README explains both documented important placements, grouped variable
values, separate marker styling, the empty default base palette, actual theme
priority and first-component wildcards. It distinguishes configured class
contexts from ordinary strings, and syntax recognition from theme coverage.
The performance example names its workload and environment and excludes editor
debounce, decoration application, document creation and file IO.

Version 0.3.0 is the local candidate version. The changelog labels its changes
Unreleased and retains the existing 0.2.0/0.1.1 history. The undated 0.2.1 entry
comes from commit `af0337ee0bbcf969aebf14b4cd6b5131117fca85`, which added the
`tailwindcss` language identifier to configured languages and CSS directive
processing. Its publication date was not inferred from a Git timestamp.

Only the manifest version and six setting descriptions changed. Configuration
names, defaults, API minimum, dependencies, source and emitted production
JavaScript are unchanged. Descriptions now identify UTF-16 length units,
literal identifiers, function/tag/collection names and ordered modifier lookup
patterns. No detection or highlighting feature was added in this slice.

## Reproduce

Use Node 24.22.1 and pnpm 10.33.0 as described in
[the toolchain guide](../toolchain.md):

```sh
pnpm install --frozen-lockfile --strict-peer-dependencies
pnpm test
pnpm run lint
pnpm run format:check
pnpm exec prettier --check README.md CHANGELOG.md package.json docs/releases
pnpm exec vsce package --no-dependencies -o tailwind-rainbow-0.3.0.vsix
```

This versioned packaging command preserves the previously tested root VSIX.
The ordinary `pnpm run build` command writes the generic `tailwind-rainbow.vsix`
filename. Archive hashes in the report identify the recorded builds; ZIP
timestamps can change hashes when rebuilding. Compare the entry list, version
and production file hashes when reviewing another build.

To inspect the candidate on a system with Python 3:

```sh
python3 - <<'PY'
import hashlib, json, zipfile
from pathlib import Path
report = json.loads(Path('docs/releases/0.3.0-verification.json').read_text())
expected = json.loads(Path('benchmarks/toolchain-update/production-node.json').read_text())
with zipfile.ZipFile('tailwind-rainbow-0.3.0.vsix') as archive:
    assert archive.testzip() is None
    assert sorted(archive.namelist()) == report['candidate']['entries']
    assert json.loads(archive.read('extension/package.json'))['version'] == '0.3.0'
    for path, digest in expected['compiledSha256'].items():
        assert hashlib.sha256(archive.read('extension/' + path)).hexdigest() == digest
    assert b'## [Unreleased]' in archive.read('extension/changelog.md')
print('Candidate version, entries and production modules verified')
PY
```
